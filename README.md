# Бот 3L

Личный Telegram-бот: присылает свежие музыкальные новости из лент 3L, склеивает дубли, а на «Нужна» добавляет трек в черновой плейлист «Сейшнс» месяца, пишет черновик поста в стиле 3L и сохраняет всё в Notion («3L / Look Listen Love → Входящие из бота»).

## Как работает
1. Каждые 10 минут GitHub запускает бота (на деле задержка 10-30 минут: GitHub опаздывает с расписанием).
2. Новые записи из лент и Telegram-каналов разбирает Claude: артист, релиз, суть по-русски, оценка «под 3L» 1-5. Синглы, клипы, альбомы и рецензии проходят при оценке от `MIN_FIT` (по умолчанию 2 - по максимуму). Прочие новости (туры, интервью) - только крупные: воссоединения, большие возвращения, распады. Российские артисты помечаются «Lost In Russia».
3. Если тот же релиз уже был в другом издании, новая карточка не приходит. Вместо этого в старой появляется «Ещё пишут: …».
4. Карточка содержит ссылки «Слушать» (Spotify, YouTube, Bandcamp - что нашлось) и кнопки **Нужна / Мимо**.
5. После «Нужна», при следующем запуске:
   - трек добавляется в приватный плейлист «Сейшнс · черновик · Месяц Год», а российский - в «Lost In Russia · черновик · Месяц Год» (бот создаёт их сам);
   - Claude пишет черновики для ВК, Telegram и Threads;
   - в Notion создаётся запись: черновики, английский оригинал статьи, все ссылки;
   - черновик приходит ответом на карточку.

Команды в чате: `/stats` - статистика за неделю, `/sources` - какие ленты работают.

## Настройка (один раз, ~40 минут)

### 1. Telegram
- В Telegram открой @BotFather → `/newbot` → придумай имя → получишь **токен**.
- Напиши своему боту `/start` (он пока молчит - это нормально).

### 2. Claude API
- console.anthropic.com → API Keys → Create Key. Пополни баланс на $5: этого хватит на месяцы.

### 3. Spotify (нужен Premium)
- developer.spotify.com/dashboard → Create app. Redirect URI: `http://127.0.0.1:8888/callback`, API: Web API.
- На Mac в Терминале, в папке бота: `python3 scripts/spotify_auth.py CLIENT_ID CLIENT_SECRET` → разреши доступ в браузере → в Терминале появится **refresh token**.

### 4. Notion
- notion.so/profile/integrations → New integration (Internal) → скопируй **токен**.
- Открой страницу «3L / Look Listen Love» → ••• → Connections → добавь эту интеграцию.

### 5. GitHub
- github.com → New repository → имя `3l-bot`, **Public** (в публичном репозитории минуты бесплатные; секреты никто не видит) → Create.
- На странице репозитория: «uploading an existing file» → перетащи всё содержимое этой папки, **кроме** папки `github-workflow` → Commit changes.
- Файл расписания: Add file → Create new file → в поле имени напиши `.github/workflows/bot.yml` → вставь содержимое `github-workflow/bot.yml` → Commit changes. (Мак скрывает папки с точкой, поэтому этот файл лежит отдельно.)
- Settings → Secrets and variables → Actions → **Secrets**:
  `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_REFRESH_TOKEN`, `NOTION_TOKEN`.
- Узнать chat id: Actions → 3L bot → Run workflow (mode: run) → в логе шага Bot будет строка `[setup] chat id: 123…`. Добавь секрет `TELEGRAM_CHAT_ID`.

### 6. Этап 0 - проверка лент
- Actions → 3L bot → Run workflow → mode: `check`. Бот пришлёт отчёт, какие ленты отвечают серверам GitHub. Нерабочие выключи в `sources.json` (`"enabled": false`).
- Дальше бот работает сам. Первый проход только запоминает текущие записи, карточки пойдут с новыми.

## Подстройка
- `sources.json` - источники, стоп-слова (`exclude`). Telegram-канал добавляется строкой `{"name": "…", "type": "telegram", "channel": "адрес_канала", "enabled": true}` - работает для любого публичного канала.
- `prompts/taste_3l.md` - вкус 3L для оценки. Добавь любимых артистов.
- `prompts/style_3l.md` - голос для черновиков: собран из `3L/_знания.md`, брендбука и 4 эталонных постов 2024 года. Правишь правила - правь здесь.
- Переменные (Settings → Variables): `MIN_FIT` - порог 1-5 (2 - больше карточек, 4 - только самое близкое).

## Этап 2 (по желанию) - мгновенные кнопки
`worker/relay.js` - бесплатный Cloudflare Worker: отвечает на нажатие сразу и запускает бота, черновик приходит примерно через минуту, а не через 10-30.

## Расходы
GitHub и Cloudflare - бесплатно. Claude - около $1-3 в месяц (разбор ~80 новостей в день быстрой моделью + черновики). Spotify - нужен Premium у владельца приложения.
